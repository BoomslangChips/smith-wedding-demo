# The Smith Wedding

A public demo of a wedding website. **James, Sophie, their guests, the estate and the village are all made up.**

Open it at https://demo.wentzel.wedding and type the invitation code `DEMO`.

- The envelope opens, and the whole invitation is there: the weekend, the venue, where to stay, what to wear, the
  wedding party, the photos and the questions.
- **What to wear** is shown by twelve 3D guests who breathe, look around and change pose. You can turn them and try
  the wedding colours on them. The bride and groom on the first page are made of the same parts.
- **Kindly Reply** takes any name you type and opens "your" invitation: who is invited, to what, when and where,
  then the reply itself (golf or the spa, the dinner, a song) and a thank-you with your own weekend.

Nothing you type is sent anywhere. There is no server behind this demo: a small script in the page answers the
page's own requests, and a reply lives in your browser tab only.

The real website this is a copy of is private: it holds a real guest list. In this copy the map of the venue, the
directions and the couple's dashboard are left out.

The 3D guests are open source (MIT): https://github.com/BoomslangChips/wedding-guests-3d

Fonts in `w/fonts` (Pinyon Script, Playfair Display, Plus Jakarta Sans) are under the SIL Open Font License 1.1. The
bodies of the 3D figures come from the MakeHuman base mesh (CC0).

The rest of this repository is the built demo, published so that it can be viewed. Written with
[Claude Code](https://claude.com/claude-code).
